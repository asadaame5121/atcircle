# AT CIRCLE ユーザー向けヘルプ

AT CIRCLE は、同じ興味を持つ個人サイトを輪のようにつなぐウェブリングです。
参加サイトに設置したウィジェットから、リング内の前後のサイトやランダムな
サイトへ移動できます。

## はじめる前に

利用には Bluesky アカウントと、公開されている自分のウェブサイトが必要です。
RSS は任意ですが、登録するとアンテナと OPML にサイトの更新情報を掲載できます。

AT CIRCLE はログイン時に ATProto OAuth を使用します。パスワードを AT CIRCLE
へ入力することはありません。許可画面に表示される権限を確認してから続行して
ください。

## 基本の使い方

### 1. Bluesky でログインする

1. ホームの「Blueskyでログイン」を選びます。
2. Bluesky のハンドルを入力します。
3. OAuth の許可画面を確認し、認証を完了します。

ログイン状態は通常7日間保持されます。共有端末では利用後にログアウトして
ください。

### 2. 自分のサイトを登録する

初回ログイン時はサイト登録画面が表示されます。Bluesky プロフィールから
見つかったサイトを選ぶか、「手動で入力する」を選んで次を入力します。

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| サイトURL | はい | `https://` などから始まる公開サイトのURL |
| サイト名 | はい | リングの参加者一覧に表示する名前 |
| 説明 | いいえ | 500文字以内 |
| RSS Feed URL | いいえ | RSS または Atom フィードのURL |

登録後はダッシュボードの「サイト編集」から変更できます。「PDSから同期」は
ATProto 側のリング情報を読み直してローカル表示を更新します。

### 3. リングを探して参加する

1. 「ウェブリングを探す」で公開中のリングを開きます。
2. リングの詳細、参加サイト、承認方式を確認します。
3. 参加操作を選び、必要に応じてサイト情報を確認します。

承認方式が「自動承認」のリングにはすぐ参加できます。「要承認」のリングでは
オーナーの承認後に参加状態になります。同じリングへの重複参加・重複申請は
できません。

リングの AT URI を受け取った場合は、ダッシュボードの「ウェブリング参加」から
URI を入力して参加できます。

### 4. ウィジェットを設置する

参加中のリングで「コードを取得」を選び、表示を調整して生成コードを自分の
サイトへ貼り付けます。

利用できる形式は次のとおりです。

- HTMLリンク: スクリプトを使わない「前へ・ランダム・次へ・一覧」のHTML
- シンプル: `widget.js` と `<webring-nav>` を使う埋め込み表示
- バナー: バナー画像またはリング名から一覧ページへリンクする表示

テーマはシステム、ライト、ダークから選べます。背景透過、表示ラベル、外部
CSS URL、一覧のリンク先、外部バナー URL も調整できます。バナーをアップロード
する場合は JPEG、PNG、WebP のいずれかで、1 MB 以下にしてください。

生成されたコードをコピーしてサイトの HTML へ貼り付けます。サイト公開後、
リング管理者は「設置確認」でウィジェットの存在を確認できます。

前後移動はリングの端で循環します。移動対象は、承認済みで有効な参加サイト
です。

## リングを作成・管理する

### リングを作成する

ダッシュボードの「ウェブリング作成」でリング名と説明を入力します。作成直後
は「募集中」「自動承認」で、作成者の登録サイトが参加します。

作成後の「ウェブリング設定」では次を変更できます。

- リング名（1〜100文字）と説明（500文字以内）
- 公開状態: 募集中または締切
- 承認方式: 自動承認または要承認
- 管理者 DID
- 公開 URL スラッグ
- バナー画像 URL

公開 URL スラッグは3〜32文字の小文字英数字とハイフンを使用し、他のリングと
重複しない値にします。設定すると `/r/スラッグ` 形式の公開 URL を利用できます。

「招待リンクをコピー」でリングへの案内を共有できます。リンクを受け取った人
がログインして参加操作を行います。

### 参加申請とメンバーを管理する

要承認のリングでは、ダッシュボードに承認待ちの申請が表示されます。内容を
確認して承認または拒否します。

メンバー管理では、参加状態の変更、キック、ブロック、ウィジェット設置確認を
行えます。

- キック: 現在の参加を解除します。対象者は再申請できます。
- ブロック: リング独自のブロック記録を作成し、対象者を参加対象から除外します。
- ブロック解除: ブロック記録を削除します。

リングの削除は取り消せません。参加情報や申請情報にも影響するため、確認して
から実行してください。

## 公開機能

### リング一覧とリング詳細

「ウェブリングを探す」には募集中のリングが表示されます。リング詳細では承認
済みサイトの一覧、サイトへのリンク、リング別アンテナ、OPML 出力を利用できます。

### アンテナ

アンテナは登録済み RSS の更新をまとめて表示します。全体表示とリング別表示が
あります。RSS がないサイトや、フィード取得に失敗しているサイトの更新は表示
されません。

### OPML

リング詳細の OPML 出力は、参加サイトの RSS 一覧をファイルとしてダウンロード
します。OPML に対応する RSS リーダーへインポートできます。

### 公開プロフィール

`/u/Blueskyハンドル` には、公開プロフィール、登録サイト、参加しているリング
が表示されます。表示内容は公開情報です。

## 退出・ログアウト・アカウント削除

- リングから離れる: ダッシュボードの対象リングで「離脱」を選びます。
- ログアウト: 現在のブラウザーからログイン状態を削除します。
- アカウント削除: AT CIRCLE のローカル DB にあるサイト・参加・アカウント情報を
  削除します。

アカウント削除は取り消せません。ユーザーの PDS に保存済みの独自 ATProto
レコードをすべて自動削除する操作ではありません。必要な場合は、削除前に参加
リングから離脱するなど、画面の確認文をよく読んで整理してください。

## 困ったとき

### ログインできない

- Bluesky ハンドルに `@` を付けず入力してください。
- OAuth の許可画面を閉じた場合は、最初からやり直してください。
- 続く場合は一度ログアウトし、ブラウザーを再読み込みしてください。

### サイト候補が見つからない

Bluesky プロフィールにサイト URL がない場合や、サイト情報を取得できない場合
があります。「手動で入力する」から登録してください。

### リングにすぐ参加できない

要承認のリングではオーナーの承認が必要です。募集中でないリング、申請済みの
リング、ブロックされているリングには新たに参加できません。

### ウィジェットが動かない

- 生成コードを省略せず貼り付けたか確認してください。
- シンプル／バナー形式では `widget.js` の読み込みも必要です。
- HTMLを制限するブログサービスでは、HTMLリンク形式を試してください。
- 外部 CSS や画像の URL が HTTPS で公開されているか確認してください。

### アンテナが更新されない

RSS URL が正しいか確認してください。更新の反映は即時とは限りません。サイト側
のフィードが取得できない場合は、サイト編集で RSS URL を修正してください。
